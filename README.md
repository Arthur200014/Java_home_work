# Java Home Work — 3 курс

Репозиторий с домашними работами по Java и Spring.

## Домашние работы

### hw_42_43 — Spring MVC + Spring Data JPA
Первая работа со Spring MVC без Spring Boot.

Сделано:
- сущность `User`;
- контроллер, сервис и репозиторий;
- Spring Data JPA;
- PostgreSQL;
- GET списка пользователей;
- GET пользователя по id;
- POST создания пользователя;
- сборка в WAR и запуск через Tomcat.

Папка: `hw_42_43`

---

### hw_44 — Spring Boot
Первый проект на Spring Boot.

Сделано:
- сущность `Car`;
- REST API для автомобилей;
- PostgreSQL;
- Spring Data JPA;
- создание автомобиля;
- получение списка автомобилей;

Папка: `hw_44`

### hw_45 — REST API + Swagger
Работа с документацией REST API.

Сделано:
- сущность `Account`;
- DTO для запросов и ответов;
- GET списка аккаунтов;
- POST создания аккаунта;
- OpenAPI / Swagger;
- PostgreSQL + JPA;
- пароль не возвращается в ответах API.

Папка: `hw_45`

---

### hw_46 — пагинация и обработка 404
Расширение API аккаунтов.

Сделано:
- пагинация;
- сортировка;
- собственный объект ответа страницы;
- получение аккаунта по id;
- обработка отсутствующего аккаунта;
- HTTP 404;
- Swagger-документация.

Папка: `hw_46`

---

### hw_47 — Account + Order
Добавлена работа со связанными сущностями.

Сделано:
- сущности `Account` и `Order`;
- связь заказа с аккаунтом через `ManyToOne`;
- создание аккаунта;
- создание заказа;
- проверка существования аккаунта перед созданием заказа;
- HTTP 404, если аккаунт не найден;
- получение заказов конкретного аккаунта.

Папка: `hw_47`

---

### hw_48 — Validation + GlobalExceptionHandler
Работа с валидацией входных данных и обработкой ошибок.

Сделано:
- сущности `User` и `Order`;
- Bean Validation;
- `@Valid`;
- проверка имени, фамилии, email, пароля и возраста;
- проверка обязательных полей заказа;
- собственный `NotFoundException`;
- `GlobalExceptionHandler`;
- единый JSON-ответ для 404;
- отдельный JSON со всеми ошибками валидации.

Папка: `hw_48`

---

### hw_49 — тестирование
Тестирование сервисов и контроллеров.

Сделано:
- unit-тесты сервисов через JUnit 5 и Mockito;
- тесты контроллеров через MockMvc;
- группировка тестов через `@Nested`;
- проверка успешных GET/POST запросов;
- проверка HTTP 404;
- проверка ошибок валидации;
- проверка полей JSON-ответов;
- тесты для пользователей и заказов;
- JaCoCo для отчёта по покрытию.

Папка: `hw_49`
