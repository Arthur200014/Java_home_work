# Java homework

Домашние работы по Java и Spring.

## Работы

- `hw_42_43` — Spring MVC без Spring Boot, User, JPA, PostgreSQL, Tomcat.
- `hw_44` — первый Spring Boot проект, REST API для Car, пагинация и сортировка.
- `hw_45` — Account REST API и Swagger/OpenAPI.
- `hw_46` — пагинация аккаунтов, получение по id и обработка 404.
- `hw_47` — Account + Order, связь через ManyToOne, добавление заказа пользователю.
- `hw_48` — Bean Validation, @Valid, GlobalExceptionHandler, JSON-ответы для ошибок.
- `hw_49` — тесты сервисов и контроллеров, Mockito, MockMvc, @Nested, JaCoCo.
