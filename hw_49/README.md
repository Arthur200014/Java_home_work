# Домашняя работа 49

Тестирование сервисов и контроллеров проекта с пользователями и заказами.

## Что проверяется

- сервис пользователей;
- сервис заказов;
- контроллер пользователей;
- контроллер заказов;
- успешные GET и POST запросы;
- 404 для отсутствующих данных;
- ошибки Bean Validation;
- все основные поля JSON-ответов;
- отсутствие пароля в JSON пользователя;
- покрытие через JaCoCo.

Тесты сервисов написаны на JUnit 5 + Mockito. Контроллеры проверяются через MockMvc. Тесты сгруппированы через `@Nested`.

## Запуск тестов

```bash
mvn clean test
```

После тестов отчёт JaCoCo находится здесь:

```text
target/site/jacoco/index.html
```

На macOS его можно открыть командой:

```bash
open target/site/jacoco/index.html
```

Для запуска самого приложения нужна база:

```sql
CREATE DATABASE hw49_db OWNER postgres;
```

После этого:

```bash
mvn spring-boot:run
```
